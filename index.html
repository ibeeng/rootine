Datamu bukan produk siapa-siapa

Data kamu di HP kamu. Kami nggak punya server, jadi memang nggak ada yang bisa kami jual.

  • Login Google cuma gerbang. Nggak ada akun Rootine, nggak ada password. Yang kami terima cuma nama, email, dan foto dari Google.
  • Nggak ada server kami. Data nggak pernah dikirim ke mana-mana.
  • Nggak ada analytics. Nggak ada pelacak iklan, nggak ada SDK pihak ketiga.
  • Izin cuma internet. Nggak minta kontak, lokasi, atau kamera.
  • Mau berhenti? Tetap punya datanya. Export JSON kapan saja.

Jawaban jujur, tanpa muter

Kenapa nggak di Play Store?

Biaya developer tahunan + review bikin harga naik dan rilis lambat. Lewat APK langsung, kamu dapat update lebih cepat. Ragu install APK luar Play Store? Signing key-nya bisa kamu cek sendiri (com.ibedes.rootine), atau coba versi web dulu.

Kalau data lokal, kenapa harus login Google?

Cuma buat gerbang masuk — nggak ada akun Rootine, nggak ada password. Kami cuma terima nama, email, dan foto dari Google. Data habit nggak pernah lewat server kami.

Data aman nggak kalau HP hilang?

Ada export JSON kapan aja, dan sync Telegram (paket Supporter) yang backup ke bot milikmu sendiri. HP hilang? Install ulang, restore.

Sync Telegram itu apa?

Kamu bikin bot sendiri lewat @BotFather (gratis, 2 menit), masukkan token-nya, app-nya kirim backup ke chat bot itu. Datanya lewat Telegram milikmu, bukan server kami.

Bisa di iPhone?

Versi web-nya jalan di Safari dan bisa dipasang ke home screen. APK-nya khusus Android.

Update gimana caranya?

App-nya kasih tahu lewat notifikasi, sekali tap kelar — tanpa install ulang. Kalau perubahannya native, aku kasih file APK baru.

Gimana cara bayar Rp49.000-nya?

Buka chat Telegram @ibedestudio, aku kirim QRIS atau no. rekeningnya. Bayar lewat app bank / e-wallet apa aja. Nggak bayar pun app-nya tetap jalan penuh.

Worth it nggak dibanding app lain?

Habit tracker langganan biasanya Rp25.000–Rp150.000 per bulan. Ini sekali Rp49.000, atau gratis kalau mau. Datanya file JSON yang bisa kamu buka tanpa app-nya.
