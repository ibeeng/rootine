Yang benar-benar kamu pakai tiap hari

Bukan daftar fitur buat jualan. Semua ini ada di APK-nya dan sudah jalan.

5 mode pencatatan

checkbox (ya/tidak), counter (5 dari 8 gelas), number (halaman, km), timer (menit fokus + pomodoro), dan jurnal teks. Satu kebiasaan, satu mode yang paling pas.

Streak, XP & level

Tiap centang dapat 10 XP. Level naik makin lama makin berat, jadi nggak habis dalam seminggu. Ada shield untuk jaga streak pas kamu sakit atau sibuk.

Heatmap & statistik

Peta konsistensi setahun, tingkat penyelesaian per kebiasaan, tren mingguan, dan hari paling rajin kamu. Semua dihitung di HP, tanpa kirim data ke mana-mana.

91 template siap pakai

Malas mikir mau mulai dari mana? Tinggal pilih paket: Pagi, Workout, Belajar, Kesehatan, Malam, Produktivitas, atau Minimal — langsung jadi daftar kebiasaan.

Jadwal fleksibel

Harian, hari tertentu, atau “4× seminggu”. Rootine ngerti bedanya kebiasaan yang harus tiap hari dan yang boleh fleksibel — streak-nya dihitung adil.

Sync Telegram — gratis

Backup otomatis ke bot Telegram kamu sendiri. Nggak perlu bayar cloud, nggak perlu daftar server. Ganti HP, data balik dalam hitungan detik.

10 tema, termasuk terang

matrix, dracula, nord, tokyo night, catppuccin, gruvbox, one dark, monokai, amber CRT, dan paper (terang). Bukan cuma warna aksen — semuanya diganti.

Backup & restore JSON

Satu file JSON berisi seluruh riwayatmu. Simpan di Google Drive, flashdisk, atau kirim ke diri sendiri. Nggak ada yang bisa mengunci datamu.

Offline penuh

Login butuh internet sekali, sisanya nggak. Di pesawat, di gunung, di daerah sinyal jelek — catat tetap jalan. Sinkronisasi cuma saat kamu mau.

Datamu bukan produk siapa-siapa

App habit tracker lain menjual paket langganan supaya kamu bisa lihat data yang kamu sendiri bikin. Rootine kebalikannya.

  • Login Google cuma gerbang. Sekali buat masuk — nggak ada akun Rootine, nggak perlu bikin password. Yang kami terima cuma nama, email, dan foto profil dari Google.
  • Nggak ada server kami. Aplikasinya nggak pernah ngirim datamu ke tempat kami, karena tempatnya nggak ada.
  • Nggak ada analytics. Nggak ada pelacak iklan, nggak ada SDK pihak ketiga.
  • Izin minimal. Cuma internet (buat login sekali & sync opsional). Nggak minta kontak, lokasi, kamera.
  • Kalau kamu berhenti, kamu tetap punya semuanya. Export JSON kapan saja, buka di app apa pun.

Jawaban jujur, tanpa muter

Kenapa nggak di Play Store?

App ini satu orang yang bikin. Play Store butuh biaya developer tahunan, review, dan data pribadi buat akun developer — semua itu bikin harga naik dan rilis jadi lambat. Lewat APK langsung, kamu dapat update lebih cepat dan aku nggak perlu naikin harga buat nutup biaya toko. Kalau kamu ragu install APK dari luar Play Store: kamu bisa cek sendiri APK-nya (signing key-nya tetap, com.ibedes.rootine), atau pakai versi web dulu.

Kalau data lokal, kenapa harus login Google?

Login Google cuma gerbang masuk. Rootine nggak punya sistem akun sendiri — nggak ada yang perlu kamu daftarin, nggak ada password buat diingat. Yang diterima cuma nama, email, dan foto profil dari Google buat nge-bedain perangkatmu, dan itu disimpan lokal di HP kamu. Data habit-nya sendiri nggak pernah lewat server kami; begitu login, semuanya jalan offline.

Apakah data aku aman kalau HP-nya hilang?

Data utama ada di HP kamu. Makanya ada dua lapis pengaman: (1) export file JSON kapan saja — simpan di Google Drive atau kirim ke diri sendiri, dan (2) sync Telegram otomatis (paket Supporter) yang ngirim backup ke bot Telegram milikmu sendiri, jadi salinannya ada di cloud Telegram pribadimu, bukan di server pihak lain. Kalau HP hilang, tinggal install ulang dan restore.

Sync Telegram itu apa? Kenapa gratis?

Kamu bikin bot Telegram sendiri (gratis, 2 menit lewat @BotFather), masukkan token-nya ke Rootine, dan app-nya akan kirim file backup ke chat bot itu. Telegram gratis buat file seperti ini, jadi nggak ada biaya server yang perlu aku bebankan ke kamu. Nggak ada data yang lewat komputer aku.

Bisa dipakai di iPhone?

Versi web PWA-nya jalan di Safari iPhone dan bisa dipasang ke layar utama. Tapi APK-nya khusus Android. Fitur sync-nya sama di dua-duanya.

Kalau versi barunya keluar, aku dapat otomatis?

Pembeli paket Supporter dapat update versi berikutnya tanpa bayar lagi. Kalau ada versi baru, aplikasinya kasih tahu lewat notifikasi dan menu cek update — sekali tap, update terpasang tanpa install ulang APK (untuk perubahan web-nya; kalau ada perubahan native, aku tetap kasih file APK baru). Buat versi gratis, kamu bisa pakai web PWA yang selalu versi terbaru.

Gimana cara bayar Rp49.000-nya?

Tinggal buka chat Telegram @ibedestudio — aku kirim QRIS atau nomor rekeningnya, kamu scan/bayar lewat app bank atau e-wallet (GoPay, OVO, DANA, apa aja yang support QRIS). Nggak ada otomasi aneh-aneh: kabarin aja di chat abis bayar, aku ucapkan terima kasih. App-nya tetap jalan penuh tanpa bayar — kontribusi kamu dipakai buat nutup waktu development.

Harga Rp49.000 itu masuk akal nggak dibanding app lain?

Bandingkan begini: app habit tracker berlangganan biasanya Rp25.000–Rp150.000 per bulan. Setahun berarti Rp300.000 ke atas, dan berhenti bayar biasanya berarti kehilangan fitur. Rootine nggak punya langganan sama sekali — APK-nya bebas kamu download, datanya di HP kamu dalam bentuk file JSON yang bisa kamu buka tanpa app-nya. Rp49.000 itu sekali, kalau kamu mau mendukung development-nya. Nggak bayar pun app-nya tetap jalan penuh.
